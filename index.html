KeyReply Kira CLI distribution

KeyReply Kira CLI distribution repository. Pre-compiled binaries are published as GitHub Release assets; users install via their platform's package manager.

Install

macOS / Linux — Homebrew

brew tap keyreply/tap
brew install kira

Installing Homebrew on Linux

If Homebrew is not yet installed, use the official installer for your distro:

Debian / Ubuntu (deb)

sudo apt update && sudo apt install -y curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc

Fedora / RHEL / Rocky / Alma (dnf)

sudo dnf install -y curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc

CentOS / Old RedHat series (yum)

sudo yum install -y curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc

ArchLinux / Manjaro (pacman)

sudo pacman -S --needed base-devel curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc

Then install Kira:

brew tap keyreply/tap
brew install kira

Windows — winget

winget source add --name keyreply https://homebrew-tap.pages.dev/
winget install KeyReply.Kira --source keyreply

brew update && brew upgrade kira                # Homebrew
winget upgrade KeyReply.Kira --source keyreply  # winget
