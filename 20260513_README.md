# keyreply/homebrew-tap

KeyReply Kira CLI distribution repository. Pre-compiled binaries are published as
GitHub Release assets; users install via their platform's package manager.

## Install

### macOS / Linux — Homebrew

```bash
brew install keyreply/tap/kira
```

The fully-qualified name is self-trusting — no `brew trust` step needed on any
Homebrew version. The `brew tap` + short-name form works too, but requires
`brew trust keyreply/tap` when Homebrew's trusted-tap gate is on (off by
default; mainly CI runners and hardened configs).

#### Installing Homebrew on Linux

If Homebrew is not yet installed, use the official installer for your distro:

**Debian / Ubuntu (deb)**

```bash
sudo apt update && sudo apt install -y curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc
```

**Fedora / RHEL / Rocky / Alma (dnf)**

```bash
sudo dnf install -y curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc
```

**CentOS / Old RedHat series (yum)**

```bash
sudo yum install -y curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc
```

**ArchLinux / Manjaro (pacman)**

```bash
sudo pacman -S --needed base-devel curl git
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
echo 'eval "$(/home/linuxbrew/.linuxbrew/bin/brew shellenv)"' >> ~/.bashrc
source ~/.bashrc
```

Then install Kira:

```bash
brew install keyreply/tap/kira
```

### Windows — WinGet

```powershell
winget source add --name keyreply https://winget.keyreply.com/ --type Microsoft.Rest
winget install KeyReply.Kira --source keyreply
```

### Standalone binaries

Download the archive for your platform from the
[latest release](https://github.com/keyreply/homebrew-tap/releases/latest),
extract, and add `kira` to your `PATH`.

| Platform          | Archive                          |
| ----------------- | -------------------------------- |
| macOS Apple Silicon | `kira-*-darwin-arm64.tar.gz`   |
| macOS Intel       | `kira-*-darwin-x64.tar.gz`     |
| Linux x64         | `kira-*-linux-x64.tar.gz`      |
| Linux ARM64       | `kira-*-linux-arm64.tar.gz`    |
| Windows x64       | `kira-*-windows-x64.zip`       |

## Upgrade

```bash
brew upgrade keyreply/tap/kira            # Homebrew
winget upgrade KeyReply.Kira --source keyreply  # WinGet
```

## Distribution model

The upstream source ([keyreply/kira-cloudflare](https://github.com/keyreply/kira-cloudflare))
is private. CI builds standalone binaries with `bun build --compile` and
attaches them as release assets on this repository. Package managers download
directly from these assets — end users do not need access to the source repo.

## Releasing a new version

Releases are automated via `.github/workflows/cli-release.yml` in the upstream
repo. On each tag push the workflow:

1. Builds binaries for all platforms.
2. Creates a release on this repo and uploads assets.
3. Opens a PR to bump `Formula/kira.rb` and WinGet manifests.
4. After merge, Homebrew and WinGet users can upgrade.
